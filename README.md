# Trabajos - Ciencia de Datos & IA (UPTC)

Repositorio con los talleres, proyectos y actividades prácticas desarrollados en la formación de Ciencia de Datos e Inteligencia Artificial en la Universidad Pedagógica y Tecnológica de Colombia (UPTC).

## Estructura del Repositorio

- **`Tarea I Análisis Exploratorio de Datos/`**:
  - Análisis y exploración del censo de arbolado urbano de Bogotá (Fase IV).
  - Incluye informe en R Markdown (`PROYECTO_ARBOLADO_BOGOTA.Rmd`), reporte compilado (`index.html`) y conjunto de datos.

- **`Taller Práctico II/`**:
  - Proceso integral de preparación de datos y análisis exploratorio del consumo energético en sedes de la UPTC (Tunja, Duitama, Sogamoso, Chiquinquirá).
  - Incluye Notebook de Jupyter (`Taller_II_Consumo_Energetico_UPTC.ipynb`), reporte HTML (`Taller_II_Consumo_Energetico_UPTC.html`), dataset (`consumos_uptc (1).csv`) y documentación metodológica.
