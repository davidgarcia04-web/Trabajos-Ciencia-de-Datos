# Trabajos - Ciencia de Datos & IA (UPTC)

Repositorio con los talleres, proyectos y actividades prácticas desarrollados en la formación de Ciencia de Datos e Inteligencia Artificial en la Universidad Pedagógica y Tecnológica de Colombia (UPTC).

## 🚀 Portal Principal de Consulta

El repositorio cuenta con un **portal web interactivo** en la raíz:
- **[`index.html`](index.html)**: Dashboard central para consultar y visualizar directamente todos los proyectos, sus reportes HTML interactivos en vivo, descargar cuadernos (Jupyter/Rmd), bases de datos y explorar los datasets.

## Estructura del Repositorio

- **`Tarea I Análisis Exploratorio de Datos/`**:
  - Análisis y exploración del censo de arbolado urbano de Bogotá (Fase IV).
  - Incluye informe en R Markdown (`PROYECTO_ARBOLADO_BOGOTA.Rmd`), reporte compilado (`index.html`) y conjunto de datos.

- **`Taller Práctico II/`**:
  - Proceso integral de preparación de datos y análisis exploratorio del consumo energético en sedes de la UPTC (Tunja, Duitama, Sogamoso, Chiquinquirá).
  - Incluye Notebook de Jupyter (`Taller_II_Consumo_Energetico_UPTC.ipynb`), reporte HTML (`Taller_II_Consumo_Energetico_UPTC.html`), dataset (`consumos_uptc (1).csv`) y documentación metodológica.

- **`Taller 3 Fundamentos de SQL, Análisis Académico y Flujos Text-to-SQL/`**:
  - Analítica relacional sobre la base de datos `university.db` (Bloques A-E: consultas, DML, cruces INNER/LEFT JOIN, auditoría de huérfanos y agregaciones estadísticas).
  - Retos integradores de cálculo de carga académica y auditoría de cruces de horarios para flujos Text-to-SQL con IA.
  - Incluye Notebook de Jupyter (`Taller_SQL_university.ipynb`), reporte interactivo HTML (`Taller_SQL_university.html`), base de datos SQLite (`university.db`) y guía oficial (`Taller_SQL_IA_Antigravity (2).pdf`).
